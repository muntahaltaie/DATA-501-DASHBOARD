# Oil Sands Lake Analysis Dashboard

Live App: https://oil-sands-dashboard.streamlit.app/

## Overview
Interactive dashboard for analyzing water chemistry across Near, Mid, and Far distance groups in the Alberta oil sands region.

## Features
- Data filtering by lake and distance group
- PCA, ANOVA, and Random Forest analysis
- Interactive map with distance calculations
- Trend analysis over time
- Standardized units across all parameters

## Data Sources
- OSMP (Oil Sands Monitoring Program)
- Alberta Water Quality Portal

## Notes
Data were compiled from multiple monitoring programs and standardized for analysis. Variation in coverage reflects the original data sources.
